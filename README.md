# Голосовой агент для Android

Приложение, которое управляет телефоном по голосовой команде: читает экран, нажимает, вводит текст, прокручивает, открывает приложения. «Мозг» — Claude через API Anthropic.

## Как это работает

1. Касаетесь плавающей кнопки 🎤 и говорите команду (распознавание речи Android).
2. Служба доступности собирает список элементов на экране и отправляет его вместе с командой в Claude.
3. Claude отвечает действием (нажать, ввести, прокрутить, открыть приложение).
4. Действие выполняется, приходит новый экран, и так до готовности. Итог озвучивается вслух.

## Сборка без компьютера и без Android Studio

Сборку делает GitHub Actions бесплатно.

1. Создайте аккаунт на github.com и пустой репозиторий (например, `voiceagent`).
2. Создайте токен: Settings → Developer settings → Personal access tokens (classic), права `repo` и `workflow`.
3. Загрузите проект в репозиторий. С телефона удобнее всего через Termux (установить из F-Droid):

   ```
   pkg install git unzip
   unzip VoiceAgent.zip
   cd voiceagent
   git init
   git add -A
   git commit -m "init"
   git branch -M main
   git remote add origin https://ТОКЕН@github.com/ВАШ_НИК/voiceagent.git
   git push -u origin main
   ```

4. На GitHub откройте вкладку Actions → «Build APK». Через 3–5 минут внизу страницы запуска появится файл `VoiceAgent-debug-apk`. Скачайте его, распакуйте, установите `app-debug.apk`.

Если сборка упала — откройте лог шага «Build debug APK» и пришлите ошибку: код не проверялся компилятором, так что мелкие правки возможны.

## Первая настройка

1. Откройте приложение, введите ключ API (console.anthropic.com → API Keys) и нажмите «Сохранить».
2. Выдайте доступ к микрофону.
3. Android 13+: «Сведения о приложении» → ⋮ → «Разрешить ограниченные настройки». Без этого переключатель службы доступности не включится.
4. Настройки доступности → «Голосовой агент» → включить.
5. Появится синяя кнопка 🎤. Её можно перетаскивать. Состояния: 🎤 ждёт, 👂 слушает, ⏳ работает (касание отменяет).

Для проверки без голоса есть поле «Проверка текстом» в приложении.

## Безопасность

- **Подтверждение.** Нажатие на элементы с подписями вроде «Отправить», «Оплатить», «Удалить», «Подтвердить», «Позвонить» требует вашего «Разрешить» в отдельном окне. Агент не может нажать это окно сам.
- **Пароли и карты.** Поля паролей скрыты от агента, в них нельзя вводить. Текст, похожий на номер карты, не вводится.
- **Защищённые приложения.** Банки, кошельки, менеджеры паролей, диалоги разрешений и установщик пакетов агент не видит и не открывает. Список — `BLOCKED` в `AgentAccessibilityService.kt`, его можно менять.
- **Текст на экране — данные, а не команды.** Это прописано в системной инструкции, но полной гарантии от обмана через содержимое страниц нет. Не просите агента читать и выполнять недоверенные сообщения.
- **Приватность.** Пока агент работает, всё, что видно на экране, уходит в API Anthropic. Не запускайте его на экранах с тем, что не должно покидать телефон.
- Ключ API хранится в приватной памяти приложения. Для надёжности задайте лимит расходов в консоли Anthropic.

## Ограничения

- Работает только на Android. Скорость зависит от интернета: каждый шаг — отдельный запрос.
- Часть приложений (игры, Flutter, видео) плохо отдаёт элементы через доступность, и агент их «не видит».
- Распознавание речи и открытие приложений из фона на некоторых прошивках может блокироваться системой.
- Платный API: стоимость зависит от длины экранов и числа шагов. Следите за расходом в консоли.

## Устройство кода

- `AgentAccessibilityService.kt` — экран, действия, кнопка, голос, подтверждение.
- `AgentRunner.kt` — цикл агента, инструменты и системная инструкция.
- `ClaudeClient.kt` — единственный файл, который знает про API Anthropic (его можно заменить на другого провайдера).
- `MainActivity.kt`, `Prefs.kt` — настройки.
